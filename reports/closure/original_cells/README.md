# 原始收尾代码来源

这些代码从任务“训练完成了，收尾工作有哪些”的实际执行记录中恢复，
对应 2026-09-10 的 Colab 代码单元。只提取代码正文，不包含对话、认证信息或执行通道。
它们依赖当时笔记本中已创建的 `model`、`norm`、`device` 等变量，不能作为独立脚本执行。

| 文件 | 对应过程 |
|---|---|
| counterfactual.py | 正确、循环移位、合法反向动作的离线预测损失 |
| paired_setup.py | 加载两模型和归一化，按固定种子生成合法场景 |
| paired_run.py | 交替模型执行顺序、40 个回合与配对统计 |
| paired_statistics.py | 逐回合表、Wilson 区间、总体标准差和结果图 |
| assemble_closure.py | 原始报告、三组配对视频与文件校验清单的汇总 |

补充历史步骤：初次候选范围产生 19 个合法场景，随后添加 seed=2026091021，
得到已归档的 20 个场景；非法种子为 2026091000、2026091005。
最终 `scenes.json` 是重放依据，不重新抽样。当前可运行入口见
[复现说明](../../../docs/REPRODUCING.md)。
